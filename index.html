Projects

Pipeline Pulse

B2B prospect segmentation and pipeline dashboard

  • Python
  • pandas
  • SQL
  • Tableau
  • A/B testing

A sales team has hundreds of target accounts and limited time. This project answers one question: which accounts deserve outreach first, and what message should they get? I built a prospect dataset modeled on my work researching 150+ target markets, then segmented, scored, and tracked it through every deal stage.

What I built

  • A SQL schema for accounts, contacts, outreach touches, and deal stages
  • A Python scoring model that ranks accounts by fit and engagement
  • A Tableau dashboard showing conversion and drop-off by stage and segment
  • An A/B analysis comparing two outreach messages and follow-up cadences

Questions it answers

  • Which segments convert, and which only look good on paper?
  • Where do accounts stall between outreach and a meeting?
  • Does a faster follow-up cadence beat a more personalized message?

Workplace Wellness Signal

Survey analysis of workplace health and behavior

  • R
  • Python
  • Excel
  • Survey design
  • Data cleaning

Survey data is never clean, and the real skill is knowing what you can honestly conclude from it. Using a public workplace mental health survey, I cleaned and validated the data, tested which workplace factors relate to employee well-being, and wrote the findings up the way a research team or HR leader would want to read them.

What I built

  • A documented cleaning pipeline: duplicates, impossible values, free-text responses, missing data
  • Reliability checks and group comparisons across work settings
  • Regression models with plain-language interpretation
  • A two-page research brief with charts and clear limitations

Questions it answers

  • Which workplace policies are linked to healthier outcomes?
  • Which patterns survive once you control for company size and role?
  • What should an organization do first, and what can’t this data tell it?
