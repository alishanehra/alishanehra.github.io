Projects

Two projects that show how I work. Both use simulated data, so no real company or patient information is involved. The code, charts, and write-ups are on GitHub.

ER Patient Flow

Where do emergency room waits pile up, and what do long waits cost?

I simulated a year of about 20,000 emergency department visits and analyzed how waits change by acuity level, hour, and weekday. In my simulated data, lower-acuity patients arriving between 10am and 1pm waited the longest, and the share who left without being seen climbed from about 1% for waits under 30 minutes to 57% for waits over two hours. I built it because I want to work on the operations side of healthcare.

  • Python
  • pandas
  • Healthcare operations
  • Data visualization

Code and write-up on GitHub

Pipeline Pulse

Which prospects should a sales team contact first?

At Toro Intelligence I research target accounts and track them through a sales pipeline. This project applies that workflow to 1,000 simulated accounts, using SQL for the funnel, a simple priority score checked on held-out data, and an A/B test of two outreach messages. The message test showed no significant difference, and the write-up explains why a sample that size can only detect a big gap.

  • Python
  • SQL
  • A/B testing
  • Sales analytics

Code and write-up on GitHub
